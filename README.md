# eejcwebsite1

Site web Vite + React + Tailwind CSS pour l'Église Évangélique La Grâce.

## Installation

```bash
npm install
```

## Commandes

```bash
npm run dev
npm run build
npm run preview
```

## Structure

- `index.html`
- `package.json`
- `package-lock.json`
- `tsconfig.json`
- `vite.config.ts`
- `src/`

## Notes

- Le projet utilise Tailwind CSS 4 via `@tailwindcss/vite`.
- Le code source React démarre depuis `src/main.tsx`.
